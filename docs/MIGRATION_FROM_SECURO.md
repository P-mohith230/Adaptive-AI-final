# Migration & Architecture Evolution from Securo

**Target Project:** AdaptiveAI Finance Controller  
**Base Project:** Securo (`v0.15.0`)  
**Context:** Razorpay AI Buildathon — Track 04 (AI Finance Controller)  
**Date:** September 2026  

---

## 1. Context & Rationale: Why Was Securo Chosen as the Foundation?

Securo was an outstanding open-source self-hosted personal finance platform. It featured:
- A clean, modern **FastAPI (Python 3.11+)** backend with asynchronous database access via `asyncpg` and SQLAlchemy 2.0.
- A decoupled, responsive **React 19 + Vite** frontend with dark-mode theming and polished Radix UI primitives.
- An established workspace model allowing multi-tenant data isolation.
- Production-grade containerization with Docker Compose and Helm charts.

However, Securo was designed for **personal wealth and household budgeting** (bank sync via Pluggy/SimpleFin, personal expense categories, investment holding tracking, and personal invoice management).

For the **Razorpay AI Buildathon Track 04**, merchants do not need personal budgeting apps; they need an enterprise-grade **AI Finance Controller** capable of:
1. Reconciling high-velocity payment gateway transactions against ERP/OMS records and bank settlement feeds.
2. Detecting subtle fee discrepancies (MDR overcharges, GST rounding errors).
3. Investigating exceptions using LLMs bounded by deterministic mathematical checks.
4. Surfacing 1-click human-in-the-loop decision cards with full audit trails.
5. Forecasting settlement liquidity.

Rather than reinventing authentication, database pooling, and frontend scaffolding from scratch, we chose to stand on the shoulders of open-source giants. We adopted Securo as our technical foundation and transformed it into a dedicated merchant financial control platform.

## 2. Component Transformation Inventory

### 2.1 Retained Upstream Components
- **Core Application Framework:** FastAPI app lifecycle, configuration management via `pydantic-settings`, and asynchronous event loops.
- **Database Infrastructure:** PostgreSQL with `asyncpg`, Alembic migration scaffolding, and connection pooling.
- **Task Scheduling:** Redis broker integration and Celery worker infrastructure for asynchronous processing.
- **Authentication Shell:** JWT and password hashing mechanisms (extended to support merchant API key authentication).
- **Base UI Layout:** Dark/light mode switching, responsive sidebar shell, and basic data table components.

### 2.2 Substantially Modified Components
- **Workspace Model:** Re-architected from personal "Family/Freelance" budgets into multi-entity merchant accounts with Razorpay merchant IDs (`MID`), currency configs (INR), and settlement schedules (T+2).
- **Data Ingestion Pipeline:** Extended the generic statement importer into a dedicated 3-way ingestion workstation supporting Razorpay payment CSVs, bank MT940 settlement feeds, and merchant ERP order exports.
- **UI Navigation & Routes:** Removed consumer budgeting tabs (personal investments, household budgets, personal net-worth graphs) and replaced them with financial controller workflows (Reconciliation Workstation, Exception Queue, Settlement Intelligence, Audit Trail).
- **Backend API Structure:** Integrated custom API routers for `/api/v1/reconciliation`, `/api/v1/merchant-ledger`, `/api/v1/settlement`, and `/api/v1/evaluation`.

### 2.3 Newly Created Subsystems (100% AdaptiveAI Original Work)
- **3-Way Deterministic Reconciliation Engine:**
  - Ingests merchant orders, gateway transactions, and bank statements simultaneously.
  - Executes fuzzy-window matching, amount verification, and fee reconciliation.
- **Financial Exception Prioritization Engine:**
  - Computes anomaly impact scores in INR.
  - Automatically identifies root causes (`FEE_OVERCHARGE`, `SETTLEMENT_FLOAT_DELAY`, `MISSING_GATEWAY_RECORD`, `UNMATCHED_BANK_CREDIT`).
- **Groq-Powered AI Controller Assistant:**
  - Integrated `llama-3.3-70b-versatile` via Groq's high-speed inference engine.
  - Operates as a co-pilot for financial operations teams with streaming natural language explanations.
  - Strictly prevented from performing arithmetic; synthesizes verified facts generated by deterministic services.
- **Human-in-the-Loop Decision Card System:**
  - Contextual modal dialog presenting evidence, suggested accounting adjustments, and 1-click execution.
- **Settlement Intelligence & Cash Flow Forecasting:**
  - Projects expected settlement dates, bank holidays, and upcoming cash inflows.
- **Razorpay Buildathon Benchmark Suite:**
  - Automated evaluation harness executing tests against a 50+ record synthetic batch.
  - Measures match rate, precision, recall, throughput (records/sec), and exception resolution.

## 3. Visual Identity & Branding Overhaul

All consumer-facing and application-level Securo branding was replaced with **AdaptiveAI Finance Controller**:
1. **Brand Identity:** Defined new color palette: Midnight Navy (`#030712`), Deep Slate (`#0B132B`), Electric Cyan (`#00E5FF`), and Trust Emerald (`#10B981`).
2. **Logomark & Emblems:** Created custom SVG vector assets featuring the interconnected financial reconciliation node icon.
3. **Typography & UI Polish:** Upgraded styling with Inter/Outfit typography, glassmorphism cards, and fintech badge components.
4. **Localization Strings:** Cleaned up and updated application locale dictionaries (`en`, `hi`, `es`, `fr`, etc.) to replace personal finance terminology with commercial merchant reconciliation terms.
